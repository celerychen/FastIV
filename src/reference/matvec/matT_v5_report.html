根因：旧版 matT 按"输出列"并行（一个 block 管 256 列），高瘦形状 cols 小 → block 极少（8192×1024 只有 4 个）→ 绝大多数 SM 空转。 纯输出并行的硬上限 = cols 个线程 = 32 个 warp，无论怎么切 block 都喂不饱 28 个 SM。
修法：把收缩维（rows）也切成 2D 网格（COL_TILE=256，ROW_TILE=32，blockDim=256），总 warp 数从 32 暴增到 8192； 每个 block 算 [rowTile×colTile] 子块的部分积写入缓冲（仅占 A 的 1/rowTile ≤1MB，带宽可忽略），再由一个极轻归约核求和。 vec 段由全体线程并行搬入共享（非单线程串行），A 按行读（列连续 → 合并）。
结果：高瘦形状 62→142 GF（达 cuBLAS 93%），方形/宽矩阵不倒退（144–152 GF，与 cuBLAS 同档）。mat·vec 复用 v4 内核已持平 cuBLAS。
